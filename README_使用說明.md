# 玄機閣．線上命理分析 — 使用說明

## 一、快速啟動

雙擊 **`啟動網站.bat`** 即可（需已安裝 [Node.js](https://nodejs.org)，你的電腦已有 v22）。

| 頁面 | 網址 |
|---|---|
| 算命首頁 | http://localhost:3300 |
| 訪客統計後台 | http://localhost:3300/admin.html |

啟動視窗會同時顯示「區網分享」網址，同一 Wi-Fi 下的手機、其他電腦可直接開啟，瀏覽都會計入統計。停止伺服器：關閉黑色視窗或按 `Ctrl+C`。

## 二、功能一覽

- **引導式填寫**：姓名（含筆畫確認，可手動微調）→ 生辰（含時辰、晚子時）→ 血型與最想了解的面向。
- **八大命理系統**：西洋星座、生肖運程（2026 丙午馬年，以立春為界）、姓名學三才五格＋81 數理、生命靈數＋流年數、生日密碼＋誕生石、八字五行（四柱、身強弱、喜用神）、血型分析、每日塔羅。
- **綜合報告**：財運／愛情／事業／健康／貴人五運評分、下半年總論、7–12 月逐月流勢、開運處方箋（開運色、幸運數字、方位、宜忌）。
- **同一人同一天結果固定**（塔羅每日更換），可用「列印／存成 PDF」保留報告。
- **訪客統計**：總瀏覽、不重複訪客、今日數據、近 60 天趨勢圖、最近來訪紀錄（每 30 秒自動更新）。

## 三、資料與隱私

- 訪客填寫的姓名生日**只在瀏覽器本機計算，不會上傳伺服器**；伺服器僅記錄瀏覽次數與匿名裝置資訊。
- 統計資料存於 `data/stats.json`，刪除該檔即歸零。

## 四、部署上網（Railway，與 wanglai-api 同流程）

1. 雙擊 **`部署_上傳到GitHub.bat`** 推上 GitHub（第一次會要求瀏覽器授權）。
2. Railway → **New Project → Deploy from GitHub** → 選這個 repo（自動偵測 Node，啟動指令即 `npm start`，零相依免安裝）。
3. Settings → **Generate Domain** 取得公開網址。
4. （建議）加掛 Volume 讓統計不因重新部署歸零：服務 → Attach Volume，Mount Path 填 `/data`，並在 Variables 加 `DATA_DIR=/data`。

之後改版：再雙擊 `部署_上傳到GitHub.bat` 即自動 commit＋push，Railway 會自動重新部署。

其他做法：區網分享（啟動後把「區網分享」網址給同 Wi-Fi 的人）；自有主機／NAS 直接 `node server.js`。

## 五、常見問題

- **某個字查不到筆畫？** 姓名欄下方的「筆畫確認」可直接填入；康熙筆畫各流派偶有一二畫之差，也可在此微調。
- **生肖怎麼跟身分證不同？** 命理慣例生肖以「立春」為界，非農曆除夕；1–2 月初出生者常見此差異。
- **想換網站名？** 搜尋替換 `public` 資料夾內的「玄機閣」即可。
